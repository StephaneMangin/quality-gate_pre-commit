# Web Frontend Development

- Follow semantic HTML5 markup
- Ensure accessibility (ARIA labels, keyboard navigation, contrast ratios)
- Use responsive design principles (mobile-first)
- Minimize bundle size — tree-shake, lazy-load, code-split
- Sanitize any user-generated content rendered in the DOM to prevent XSS
- Use CSS custom properties for theming
- Prefer CSS Grid/Flexbox over legacy layout methods
